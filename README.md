# 🚗 AutoVenta APP — Landing Page B2B (Argentina)

Landing page comercial e informativa de alta conversión para **AutoVenta APP**, la suite digital de infraestructura automotriz para agencias, lotes de seminuevos y revendedores independientes en Argentina.

## 🌟 Características Implementadas

- **Copywriting de Respuesta Directa:** Redactado con tono B2B argentino, enfocado en resolver los problemas reales de agencias locales (curiosos en Marketplace, comisiones abusivas, fotos desordenadas en WhatsApp, oportunidades perdidas).
- **Nuevo Producto Destacado:** Sección exclusiva para el **Catálogo Web B2B**, con mockup navegable de smartphone y desglose de fichas técnicas, sincronización en tiempo real y enlace directo a WhatsApp.
- **Suite Integral (3 Pilares):**
  1. **Radar IA de Precios:** Escaneo continuo para detectar unidades entre un 15% y 30% por debajo de cotización.
  2. **Filtro Pre-Calificador Anticuriosos:** Asistente inteligente que califica presupuesto y anticipo antes de derivar el chat.
  3. **Gestor Centralizado de Inventario:** Control minucioso de stock, fichas de costo y rentabilidad bimonetaria (ARS / USD Blue).
- **Zero Price Strategy:** Sin precios en pantalla; derivación directa a **"Ver Demostración en Vivo"** y **"Consultar por WhatsApp"**.
- **Componentes Interactivos:**
  - Modal interactivo para agendar Demo Virtual 1 a 1 con formulario de captación de leads que genera el mensaje listo para WhatsApp.
  - Mockups visuales con datos reales del mercado automotor argentino (Toyota Hilux, VW Golf TSI, Cruze, Corolla).
  - Acordeón interactivo para Preguntas Frecuentes (FAQs).
  - Botón flotante permanente de WhatsApp con micro-interacción y tooltip.
  - Diseño Dark Mode B2B Premium (`#070A10`, `#0066FF`, `#00E676`, `#00D8F6`).

## 🚀 Cómo Visualizar o Ejecutar en Local

Podés abrir directamente el archivo `index.html` en cualquier navegador web, o iniciar un servidor web local rápido con Python:

```bash
# Iniciar servidor local en el puerto 3000
python3 -m http.server 3000
```

Luego abrí en tu navegador:
`http://localhost:3000`
